# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, discrimination and personal attacks aren't tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer through their GitHub profile ([@Mmolokii](https://github.com/Mmolokii)). Reports are handled confidentially. The maintainer may remove comments, commits or contributions that break this code, and may block repeat offenders.
